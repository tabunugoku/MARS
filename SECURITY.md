# Security policy

## Supported versions

Security fixes go into the latest release. Use the `1` image tag
(`ghcr.io/tabunugoku/mars:1`) to receive them as soon as they are published.

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it
privately through GitHub instead:

1. Open the repository's **Security** tab.
2. Choose **Report a vulnerability**.
3. Describe the problem, the version or image tag you run, and the steps to
   reproduce it.

You will get an answer in the advisory thread. Once a fix is released, the
advisory is published with credit to the reporter, unless you ask not to be
named.
