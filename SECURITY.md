# Security policy

## Supported versions

The supported version is the latest 0.1.x image, `ghcr.io/tabunugoku/mars:0.1`.
Security fixes go into that image, so run the newest one to get them.
If you build MARS from source, use the latest `main` branch.

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it
privately through GitHub instead:

1. Open the repository's **Security** tab.
2. Choose **Report a vulnerability**.
3. Describe the problem, the version or commit you run, and the steps to
   reproduce it.

You will get an answer in the advisory thread. Once a fix is released, the
advisory is published with credit to the reporter, unless you ask not to be
named.
