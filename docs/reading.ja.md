# 読む

この資料ではホーム画面から Web リーダーまでの、本を探して読むための操作を説明します。

## ホーム画面

ホーム画面には、次の項目が並びます。

- **読みかけ**: 途中まで読んだ巻です。
- **次に読む**: 読み終えた巻の続きにあたる巻です。
- **最近追加された巻**
- **新しいシリーズ**
- **最近更新されたシリーズ**
- **最近読んだ巻**

ライブラリがまだないときは、「まだ本がありません」と表示されます。その場合は、管理 > ライブラリ設定 でフォルダを追加してください。

## 検索

サイドバーの「検索」（スマートフォンでは下部のタブ）から検索します。検索欄には「タイトル・著者名・ISBN」と表示されます。

結果は次のタブに分けて表示されます。

- すべて
- シリーズ
- 巻
- コレクション
- リーディングリスト

最近の検索は検索欄の下に表示されます。「すべて消去」で消せます。

## 一覧の絞り込みと並べ替え

ライブラリやシリーズの一覧では、既読状態、ステータス、ジャンル、タグ、出版社、言語、著者、年齢制限などで絞り込めます。

## コレクション

コレクションはシリーズを好きな単位でまとめるものです。

- 作成: コレクションの画面で「新規作成」を押します（管理者のみ）。
- 追加: シリーズのメニューから「コレクションに追加」を選びます。
- 並び順: 「手動で並べる」を選ぶと、順番を自分で決められます。並び順を自動にすることもできます。

## リーディングリスト

リーディングリストは巻を読む順に並べたものです。

- 作成: リーディングリストの画面で「新規作成」を押します（管理者のみ）。
- 追加: 巻のメニューから「リーディングリストに追加」を選びます。
- CBL の取り込み: ComicRack の `.cbl` ファイルを「CBL を読み込む」から取り込めます。ファイルは 5 MB 以下にしてください。取り込む前に、一致した本の数と一致しなかった本の数が表示されます。「作成」を押すと、リーディングリストが作られます。

CBL で一致しなかった本は、リーディングリストに入りません。シリーズ名と番号が、MARS の本と一致しているかを確認してください。

## Web リーダー

### 開く

巻の画面で、次のどれかを押すと、リーダーが開きます。

- 続きから読む
- 読む
- 最初から読む

### ページの送り方

| 操作 | 内容 |
| --- | --- |
| 画面の左右の端をタップ | 前後のページに移ります。 |
| 画面の中央をタップ | 上部と下部のバーを表示または非表示にします。 |
| 左右にスワイプ | ページを送ります。 |
| ← → | ページを送ります。読み方向に従います。 |
| 上下の矢印キー | 縦読みのときに、ページを送ります。 |
| Space / PageDown | 次のページへ進みます。 |
| PageUp | 前のページに戻ります。 |
| Home / End | 最初のページ、最後のページへ移ります。 |
| M | バーを表示または非表示にします。 |
| Esc | 開いているパネルを閉じます。パネルがなければ、リーダーを閉じます。 |

読み方向が右から左の場合、画面の左側が次のページになります。キーの ← と → も同じように逆になります。

縦スクロール（Webtoon）では、キーでのページ送りは使えません。スクロールして読みます。

### 表示設定

リーダーの上部バーの「表示設定」から、表示を変えられます。

| 項目 | 選べる値 |
| --- | --- |
| 読み方向 | 右→左、左→右、縦、縦スクロール |
| 見開き | 単ページ、見開き、表紙だけ単ページ |
| 表示サイズ | 画面、幅、高さ、原寸 |
| 背景 | 黒、グレー、白 |

設定を変えられる範囲は、「使う設定」で選びます。

- **全体設定**: すべての作品に使われます。PC 用とモバイル用に分けて持てます。
- **シリーズ共通**: そのシリーズの全巻に使われます。
- **この巻だけ**: その巻だけに使われます。

全体設定は設定 > リーダー でも変えられます。「縦長の画面では、横長のページを 2 ページに分ける」を有効にすると、見開きで取り込まれた横長のページを、読む順に半分ずつ表示します。

### ページ一覧

上部バーの「ページ一覧」を開くと、ページのサムネイルが並びます。見たいページを押すと、そのページに移ります。

### シークレットモード

上部バーの「シークレット」を有効にすると、読書の進捗を保存せずに読めます。巻のメニューの「シークレットモードで読む」からも開けます。

### 巻の終わり

最後のページまで読むと、「○○を読み終わりました」と表示されます。

- 次の巻があれば、「次の巻を読む」を押せます。
- 次の巻がなければ、「このシリーズの最新巻です。」と表示されます。「シリーズに戻る」から、シリーズの画面に戻れます。

## 読書の進捗

読んでいる位置はユーザーごとに保存されます。同じアカウントで使っている別の端末にも反映されます。シークレットモードで読んだ場合は、保存されません。

## 既読と未読

既読と未読は、次のように切り替えられます。

- 巻: 巻のメニューから「既読にする」または「未読にする」を選びます。
- シリーズ: シリーズの画面で「既読にする」または「未読にする」を押します。
- ライブラリ: ライブラリの画面で「ライブラリを既読にする」または「ライブラリを未読にする」を押します。
- 複数の巻やシリーズ: 一覧で複数の項目を選ぶと、操作のバーが表示されます。そこから「既読にする」または「未読にする」を選びます。

## ダウンロード

ダウンロードには、権限が必要です。管理者は常にダウンロードできます。一般ユーザーは、管理者が「ファイルのダウンロードを許可」を有効にしている場合だけ、ダウンロードできます。

- 巻: 巻のメニューから「ファイルをダウンロード」を選びます。元のファイルがそのまま保存されます。
- シリーズ: シリーズのメニューから「まとめてダウンロード（ZIP）」を選びます。シリーズの全巻が ZIP にまとめられます。

## PDF

リーダーで読める PDF はリーダーで開きます。PDF をブラウザの表示で見たい場合は、巻のメニューの「ブラウザで開く」を選びます。

リーダーで読めない PDF（暗号化されているなど）は、「ブラウザで開く」だけが使えます。

PDF の扱いの詳細は[ライブラリとスキャン](libraries.ja.md#pdf-の扱い)を参照してください。

## スマートフォンへのインストール

MARS はホーム画面に追加して使える Web アプリです。

- iOS Safari: 共有メニューの「ホーム画面に追加」を選びます。
- Chrome、Edge、Android: 「アプリをインストール」を選びます。

インストールできるのは、HTTPS か `localhost` で開いている場合だけです。LAN 上で `http://` のアドレスを開いている場合は、ブラウザで使えますが、インストールは表示されません。HTTPS の設定は[Docker での導入](install/docker.ja.md)を参照してください。

インストールされたアプリは、読書の内容や本のデータを保存しません。保存するのは、アプリの画面の部品だけです。オフラインでは読めません。

## 表示言語

表示言語は設定 > アカウント の「表示言語」で切り替えます。選べるのは、次のとおりです。

- 日本語
- English
- ブラウザに合わせる

名前やパスワードの変更を保存していない場合は、先に保存するか取り消してください。
