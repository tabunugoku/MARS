# ユーザーと権限

この資料では最初の管理者の作成、ユーザーの追加、権限、API キー、パスワードの変更を説明します。

## 最初の管理者を作る

管理者がまだいない間、ログイン画面には「初期設定」のフォームが表示されます。

1. サーバーを初めて起動すると、セットアップトークンが表示されます。トークンは起動時のログと、データフォルダの `setup-token` ファイルに書かれています。

   ```sh
   docker logs mars 2>&1 | grep token=
   ```

   データフォルダをホストに置いている場合は、`setup-token` ファイルを直接開けます。Docker イメージにはシェルがないため、`docker exec` は使えません。詳しくは [Docker での導入](install/docker.ja.md) を参照してください。

2. 初期設定のフォームに、次の項目を入力します。

   | 項目 | 内容 |
   | --- | --- |
   | セットアップトークン | 上で確認したトークンです。 |
   | 名前 | 管理者の表示名です。 |
   | メールアドレス | ログインに使います。 |
   | パスワード | 8 文字以上です。 |
   | パスワード（確認） | 同じパスワードを入力します。 |

3. 「はじめる」を押します。

管理者が作られると、セットアップトークンは削除されます。以後は、このフォームは表示されません。

## 管理者と一般ユーザー

ユーザーには、2 つの役割があります。

| 役割 | できること |
| --- | --- |
| 管理者 | 管理の画面をすべて使えます。ライブラリ、ユーザー、サーバー設定を変更できます。すべてのライブラリが見えます。ダウンロードとページの閲覧も、常にできます。 |
| 一般 | 管理の画面は使えません。見られるライブラリと、ダウンロードやページの閲覧の権限は、管理者が設定します。 |

## ユーザーを追加する

管理 > ユーザー で、「ユーザーを追加」を押します。次の項目を入力します。

| 項目 | 内容 |
| --- | --- |
| 名前 | ユーザーの表示名です。 |
| メール | ログインに使います。 |
| パスワード | 初めのパスワードです。ユーザーは、あとで変えられます。 |
| 役割 | 管理者または一般です。 |
| ファイルのダウンロードを許可 | 有効にすると、本のファイルをダウンロードできます。 |
| ページのストリーミングを許可 | 有効にすると、リーダーでページを読めます。 |
| ライブラリ | 「すべてのライブラリ」を有効にするか、見せるライブラリを選びます。 |

ユーザーを編集するには、一覧の「編集」を押します。パスワードの欄は変えるときだけ入力します（「新しいパスワード（変更するときだけ）」）。

ユーザーを削除すると、そのユーザーはサインインできなくなります。

## ライブラリごとのアクセス

一般ユーザーは許可されたライブラリの中の本だけを見られます。許可されていないライブラリのシリーズや巻は、表示されません。URL を直接開いた場合も、見つからないと表示されます。

## 権限

### ファイルのダウンロード

「ファイルのダウンロードを許可」が有効なユーザーは、次の操作ができます。

- 巻のメニューの「ファイルをダウンロード」
- シリーズのメニューの「まとめてダウンロード（ZIP）」
- OPDS アプリでの本のダウンロード

### ページのストリーミング

「ページのストリーミングを許可」が有効なユーザーは、リーダーでページを読めます。

この権限がないユーザーは、OPDS アプリでもページを読めません。OPDS のフィードには、ページを読むための情報（OPDS-PSE）が表示されなくなります。

## API キー

API キーはパスワードの代わりに使う長い文字列です。OPDS アプリや Mihon の Komga 拡張などで使えます。

### 作成

アカウント（設定 > アカウント）の「API キー」で、次の操作をします。

1. 「APIキーの名前」に、キーの用途がわかる名前を入力します（例: `Panels`）。
2. 「作成」を押します。
3. 表示されたキーを、接続するアプリに貼り付けます。

キーは作成したときに一度だけ表示されます。画面を閉じると、キーの値はもう表示されません。忘れた場合は、キーを削除して作り直してください。

一覧には、キーの作成日と最終使用日が表示されます。

### 削除

キーを削除すると、そのキーを使っているアプリは接続できなくなります。使わなくなったキーは削除してください。

### 使い方

API キーは次のどちらかの方法で送ります。

- `Authorization: Bearer <API キー>` ヘッダー（REST API）
- パスワードの欄に入力する（OPDS アプリや Komga 互換 API）。ユーザー名は任意の文字列で構いません。

REST API の例は[API](api.ja.md) を参照してください。

## パスワード

### 自分のパスワードを変える

設定 > アカウント の「パスワード」で、次の項目を入力します。

- 現在のパスワード
- 新しいパスワード（8 文字以上）
- 新しいパスワード（確認）

「パスワードを変更」を押します。

### 表示名とメールアドレス

表示名は設定 > アカウント の「プロフィール」で変えられます。メールアドレスは管理者に変更を頼んでください。

## ログイン状態の保持

ログイン画面の「ログイン状態を保持する」を有効にすると、ログイン状態は既定で 30 日間続きます。日数は管理 > サーバー設定 の「ログイン保持の日数」で変えられます。

無効にした場合、ログイン状態はブラウザを閉じると終わります。
