# Komga 機能一覧と採否

【必須】は MVP に入れる。【推奨】は MVP の後すぐ、【後回し】は需要を見て判断する。採否を変えたらこのファイルを更新する。

採用案として【必須】【推奨】【後回し】の印を付けた。最終的な採否はユーザーが決める。

### A. ライブラリ管理
- 【必須】複数ライブラリの登録（フォルダ単位）
- 【必須】ライブラリのスキャン（手動・定期・起動時）
- 【推奨】ファイル変更の監視による自動スキャン
- 【推奨】詳細スキャン（ファイル更新の有無を問わず再解析する）
- 【必須】対応形式：CBZ/ZIP、CBR/RAR（RAR5 を含む）
- 【推奨】CB7/7z、PDF
- 【後回し】EPUB（固定レイアウトとリフロー）、Divina
- 【推奨】除外パターンの指定（ディレクトリ・ファイル）
- 【後回し】Oneshots ディレクトリ（単話をそれぞれ独立したシリーズとして扱う）
- 【推奨】ゴミ箱（消えたファイルを残しておき、あとで空にする）
- 【後回し】ファイルハッシュによる重複ファイルの検出、ページハッシュによる重複ページ（広告ページなど）の検出と削除
- 【後回し】CBZ への変換、誤った拡張子の修正
- 【後回し】ライブラリ外のファイルの取り込み（コピーまたは移動）

### B. メタデータ
- 【必須】ファイル名やフォルダ構造からのシリーズ・巻の自動判定
- 【推奨】ComicInfo.xml の取り込み
- 【後回し】EPUB メタデータ、Mylar の series.json、ISBN バーコードの読み取り
- 【推奨】ローカルのカバー画像（cover.jpg など）の取り込み
- 【必須】シリーズのメタデータ：タイトル、ソート用タイトル、ステータス、あらすじ、出版社、読み方向、年齢区分、言語、ジャンル、タグ、総巻数、リンク、別名タイトル
- 【必須】巻のメタデータ：タイトル、巻数、ソート番号、あらすじ、発売日、著者（役割別）、タグ、ISBN、リンク
- 【推奨】Web UI からのメタデータ編集（単体編集と一括編集）
- 【推奨】フィールドのロック（スキャンで上書きさせない）
- 【推奨】サムネイルの選択とアップロード
- 【後回し】シリーズのメタデータを巻から集約する（著者・タグ・発売日）
- 【後回し】共有ラベル（閲覧制限に使う）

### C. 整理・閲覧
- 【必須】ダッシュボード：続きを読む、次に読む（On Deck）、最近追加された巻・シリーズ、最近更新されたシリーズ、最近読んだ巻
- 【必須】ライブラリやシリーズの一覧（グリッド表示、ソート、フィルター）
- 【推奨】フィルター：既読状態、ステータス、ジャンル、タグ、出版社、言語、年齢区分、著者、完結
- 【必須】検索（シリーズ、巻、コレクション、リーディングリスト）
- 【推奨】コレクション（シリーズをまとめる。手動順と自動順を選べる）
- 【推奨】リーディングリスト（巻をまとめる。CBL ファイルの取り込みに対応）
- 【推奨】既読・未読の一括設定
- 【後回し】出版社・ジャンル・タグなどの閲覧ページ

### D. Webリーダー
- 【必須】ページ単位の表示（左→右、右→左、縦方向）
- 【必須】Webtoon のような縦スクロールの連続表示
- 【必須】見開き表示（表紙だけを単ページにする設定を含む）
- 【必須】拡大縮小モード（幅・高さ・画面に合わせる、原寸）
- 【必須】ページの先読み、キーボード・タッチ・クリック領域による操作
- 【必須】読書進捗の保存と同期、次の巻への移動
- 【推奨】シークレットモード（進捗を保存しない）
- 【推奨】背景色の設定、ページ一覧（サムネイル）からのジャンプ
- 【後回し】EPUB リーダー（フォント設定、テーマ）
- 【推奨】PDF の表示（画像に変換して表示するか、ブラウザで直接開く）

### E. ユーザー・認証
- 【必須】複数ユーザー、管理者と一般ユーザー
- 【推奨】権限：ファイルのダウンロード、ページのストリーミング
- 【推奨】ライブラリ単位のアクセス制限
- 【後回し】年齢区分やラベルによる閲覧制限
- 【推奨】API キー
- 【後回し】OAuth2 / OIDC によるログイン
- 【推奨】ログイン状態の保持（Remember me）
- 【後回し】認証履歴（アクティビティログ）

### F. 外部連携
- 【必須】REST API（OpenAPI ドキュメント付き）
- 【推奨】OPDS v1.2（電子書籍アプリから使う）
- 【後回し】OPDS v2
- 【後回し】Kobo 同期（Kobo 端末にストアとして見せる）
- 【後回し】KOReader の進捗同期
- 【推奨】Mihon/Tachiyomi 互換 API（Komga 拡張がそのまま使えるようにする）
- 【後回し】Komf（外部メタデータ取得ツール）との互換
- 【推奨】サーバー送信イベント（SSE）による UI のリアルタイム更新

### G. 管理・その他
- 【必須】サーバー設定（ポート、タスクのスレッド数、サムネイルのサイズ）
- 【推奨】タスクキューの表示（スキャン・解析の進み具合）
- 【推奨】メディア管理：解析エラーの巻、不足ファイル、重複の一覧
- 【推奨】サムネイルの再生成、メディアの再解析
- 【推奨】巻ファイルのダウンロード、シリーズの一括ダウンロード（ZIP）
- 【必須】ダークモード
- 【推奨】PWA 対応、スマホ向けのレイアウト
- 【推奨】多言語対応（最初は日本語と英語）
- 【後回し】お知らせの表示、更新の確認
