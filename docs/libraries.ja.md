# ライブラリとスキャン

MARS はライブラリとして登録したフォルダの中の本のファイルを読み、シリーズと巻を作ります。この資料では対応する形式、フォルダの組み方、ライブラリの登録、スキャンの仕組みを説明します。

## 対応形式

| 形式 | 拡張子 | 補足 |
| --- | --- | --- |
| CBZ / ZIP | `.cbz`, `.zip` | |
| CBR / RAR | `.cbr`, `.rar` | RAR5 と solid アーカイブを含みます。 |
| CB7 / 7z | `.cb7`, `.7z` | |
| PDF | `.pdf` | 下の説明を参照してください。 |

拡張子が上の表にないファイルは、本として扱われません。

### PDF の扱い

PDF は次のように表示されます。

- 1 ページが 1 枚の画像だけでできているページは、その画像をそのまま表示します。
- それ以外のページは pdfium で PNG に描いてから表示します。
- 暗号化されているなど、解析できない PDF はリーダーでは開けません。この場合は、本のメニューの「ブラウザで開く」からブラウザの PDF 表示で開きます。
- 512 MB を超える PDF は読めません。

## フォルダ構成

MARS は、本のファイルが直接入っているフォルダを 1 つのシリーズとして扱います。

- 本のファイルがあるフォルダごとに、シリーズが 1 つ作られます。サブフォルダも同じ規則で扱います。
- ライブラリのルート直下にある本のファイルは、1 冊ずつ独立したシリーズになります。読み切りの作品に向いています。
- シリーズ名はフォルダ名から作られます。末尾の `(2019)` のような年号と、`[tag]` のような角括弧は取り除かれます。

例を示します。

```text
comics/
  作品A/
    作品A 01.cbz
    作品A 02.cbz
    作品A 03.cbz
    cover.jpg
  作品B (2019)/
    作品B 第1巻.cbz
  読切作品.cbz
```

この例では次のようになります。

- 「作品A」というシリーズが作られ、3 冊の巻が入ります。`cover.jpg` は表紙に使われます（後述）。
- 「作品B」というシリーズが作られます。フォルダ名の `(2019)` は取り除かれます。
- 「読切作品」は 1 冊だけのシリーズになります。

### 巻の番号

巻の番号はファイル名から次の順に探します。最初に見つかったものを使います。

1. `第5巻`, `第3話`, `第2集` のような「第 N 巻・話・集」
2. `vol 5`, `volume 5`, `v5` のような表記
3. `#7` のような表記
4. `5巻`, `3話` のような表記
5. それ以外の場合は、ファイル名の中で最後の数字

小数の番号（`3.5` など）も使えます。`[2019]` のような角括弧の 4 桁の年号と、`1920x1080` のような解像度は、番号として使いません。

番号が見つからないファイルは、ファイル名の順に並べて番号が振られます。巻が追加または削除されると、番号は振り直されます。

### ファイル名の順

シリーズと巻は、自然順（`2` は `10` より前に並ぶ順）で並びます。

## ComicInfo.xml と表紙画像

### ComicInfo.xml

ComicInfo.xml が入っている本では、その内容を読み込みます。この設定は既定で有効です（「ComicInfo.xml を読み込む」）。

- 巻の番号は、ファイル名より ComicInfo.xml の `Number` が優先されます。
- 巻のタイトル、あらすじ、発売日、ISBN、著者、タグを読み込みます。
- シリーズの項目は、巻番号が最も小さい巻の ComicInfo.xml から読み込みます。
- ComicInfo.xml の `Manga` が `YesAndRightToLeft` の場合は、右から左に読む作品として扱います。

### フォルダの表紙画像

シリーズのフォルダ直下に次のどれかの名前の画像があると、それがシリーズの表紙になります（「フォルダ内の表紙画像を使う」。既定で有効です）。

- 名前: `cover`, `folder`, `poster`（大文字と小文字は区別しません）
- 拡張子: `.jpg`, `.jpeg`, `.png`, `.webp`

サブフォルダの中は探しません。

## ライブラリの追加

管理 > ライブラリ設定 > 「ライブラリを追加」から登録します。

| 項目 | 内容 |
| --- | --- |
| 名前 | ライブラリの表示名です。 |
| フォルダ | サーバー上の絶対パスを入力します。Docker では、マウント先のパス（例: `/comics`）を入力します。 |
| 種別 | マンガ、Webtoon、コミック、書籍のいずれかです。作品の読み方向の既定値が変わります（下の表）。 |
| スキャン間隔 | しない、1時間ごと、毎日、毎週のいずれかです。既定は毎日です。 |
| ComicInfo.xml を読み込む | 既定で有効です。 |
| フォルダ内の表紙画像を使う | 既定で有効です。 |
| ファイルの変更を監視して自動でスキャンする | 既定で無効です。 |
| 除外パターン | 除外するファイルとフォルダを 1 行に 1 つずつ書きます。 |

フォルダは「選ぶ」ボタンからも指定できます。「選ぶ」を押すと「フォルダを選ぶ」の画面が開き、サーバー上のフォルダを一覧から選べます。名前が `.` で始まるフォルダは一覧に出ません。

作成したあとは、フォルダを変更できません。「フォルダは作成後に変更できません」と表示されます。別のフォルダを使う場合は、新しいライブラリを作ってください。

| 種別 | 作品の読み方向の既定値 |
| --- | --- |
| マンガ | 右から左 |
| Webtoon | 縦スクロール |
| コミック、書籍 | 左から右 |

### 自動で除外されるもの

次のファイルとフォルダは、スキャンの対象になりません。

- 名前が `.` で始まるファイルとフォルダ
- `@eaDir`, `#recycle`, `#snapshot`, `$RECYCLE.BIN`, `System Volume Information`, `lost+found`, `__MACOSX` という名前のフォルダ

### 除外パターン

除外パターンは 1 行に 1 つ書きます。書き方はシェルのワイルドカードと同じです。

- `*` は任意の文字列（`/` を除く）に一致します。
- `?` は任意の 1 文字に一致します。
- `[abc]` は括弧の中のいずれか 1 文字に一致します。

パターンは、ライブラリのルートからの相対パス、またはファイル名やフォルダ名だけと比べられます。一致したフォルダはその中身もすべて除外されます。

除外パターンの例を示します。

```text
@eaDir
*.part
下書き
```

## スキャン

スキャンは次の 3 つのタイミングで行われます。

- **手動**: ライブラリ一覧の「スキャン」ボタン（更新のアイコン）を押します。
- **定期**: スキャン間隔で設定した間隔ごとに行われます。
- **起動時**: サーバーを起動するたびに、すべてのライブラリが 1 回スキャンされます。

スキャンの進み具合は管理 > タスク で確認できます。

### 詳細スキャン

通常のスキャンは変更があったファイルだけを解析します。詳細スキャンは変更のないファイルも含めてすべての本を解析し直します。冊数が多いと時間がかかります。

ライブラリ設定で対象のライブラリを編集し、ダイアログの「メンテナンス」の欄にある「詳細スキャン」から実行できます。

### ファイルの変更の監視

「ファイルの変更を監視して自動でスキャンする」を有効にすると、フォルダの変更を検知します。変更が止まってから約 30 秒後に、そのライブラリをスキャンします。

次の点に注意してください。

- SMB や NFS などのネットワーク共有では、変更を検知できないことがあります。定期スキャンと併用してください。
- Linux では、監視できるフォルダ数に上限があります。上限に達すると、ライブラリの一覧に監視が動いていない理由が表示されます。その場合も、定期スキャンは動き続けます。上限を増やす方法は[トラブルシューティング](troubleshooting.ja.md#監視が効かない)を参照してください。

### シンボリックリンク

ライブラリのルートフォルダがシンボリックリンクの場合は、リンク先のフォルダをスキャンします。

ルートの内側にあるシンボリックリンクは、ファイルもフォルダもたどりません。

## ゴミ箱

ファイルが見つからなくなったシリーズと巻は、削除されずにゴミ箱に入ります。同じ場所にファイルが戻ると、次のスキャンで自動的に元に戻ります。

ゴミ箱は管理 > メディア管理 の「ゴミ箱」タブで開きます。

- 「消す」: 一覧から 1 件だけ消します。ファイルには触れません。
- 「ゴミ箱を空にする」: ゴミ箱の中身をすべて一覧から消します。ファイルには触れません。元に戻せません。

ライブラリを削除しても、ファイルは削除されません。削除されるのは、MARS への登録だけです。

## メタデータの編集とロック

シリーズや巻のメタデータは、「メタデータを編集」から変更できます（管理者のみ）。複数のシリーズをまとめて変更するには、ライブラリの一覧でシリーズを選んでから「一括編集」を使います。複数の巻のタグは、シリーズの画面で巻を選んでから「タグを編集」でまとめて変更できます。

変更した項目は自動でロックされます。ロックされた項目はスキャンや ComicInfo.xml で上書きされません。項目ごとに「○○をロック」のスイッチで、ロックを切り替えられます。

## サムネイル

表紙に使うサムネイルは管理 > サーバー設定 の「サムネイル」で設定します。

- サイズ: 小、中、大、特大から選びます。
- 形式: JPEG、WebP、AVIF から選びます。

設定の変更は新しく作るサムネイルから適用されます。既にあるサムネイルは「表紙を作り直す」で作り直せます。OPDS と Komga 互換 API には常に JPEG で返します。

「表紙を作り直す」は、管理者が次の場所から実行できます。

- ライブラリ: ライブラリ設定の編集ダイアログの「メンテナンス」にあります。
- シリーズ: シリーズの画面のメニューにあります。
- 巻: 巻の詳細の「その他」の中にあります。

巻の詳細の「その他」からは「表紙の画像をアップロード」で表紙の画像を差し替えることもできます。差し替えた画像を外してページから作った表紙に戻すには、「表紙を作り直す」を使います。
