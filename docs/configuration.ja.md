# 設定

MARS の設定は 2 つの場所にあります。

- **環境変数**: 起動時に読み込まれる設定です。データの場所や待ち受けアドレスなど、サーバーを起動する前に決める値を指定します。
- **サーバー設定画面**: 管理者が Web UI で変更する設定です。変更はデータベースに保存されます。画面は **管理 > サーバー設定** にあります。

## 環境変数

| 変数 | 既定値 | 意味 |
| --- | --- | --- |
| `MARS_DATA` | イメージでは `/data`。バイナリでは起動したフォルダの下の `data` | データベース、サムネイル、ページのキャッシュを保存するフォルダ |
| `MARS_PORT` | `25600` | 待ち受けるポート。設定すると、サーバー設定画面の「ポート」より優先されます。Docker イメージでは `25600` が設定済みです |
| `MARS_HOST` | 空（すべてのインターフェース） | 待ち受けるアドレス。例: `127.0.0.1`。詳しくは [待ち受けアドレス](#待ち受けアドレス) を参照してください |
| `MARS_TRUSTED_PROXIES` | なし | 信頼するリバースプロキシの IP アドレスまたは CIDR。複数ある場合はカンマで区切ります。詳しくは [リバースプロキシ](#リバースプロキシ) を参照してください |
| `MARS_DEV` | 未設定 | `1` にすると API だけを提供します。UI は Vite の開発サーバーが提供します。開発用の設定です |
| `GOMEMLIMIT` | コンテナの上限から設定 | コンテナにメモリの上限があると、その 4 分の 3 が自動で設定されます。この変数を設定すると、代わりにその値が使われます |

環境変数を変更したら、サーバーを再起動してください。

## リバースプロキシ

MARS を Caddy、Traefik、nginx などのリバースプロキシの背後で動かす場合は、次の設定をしてください。

### 信頼するプロキシ（MARS_TRUSTED_PROXIES）

`MARS_TRUSTED_PROXIES` には MARS から見たプロキシの接続元アドレスを設定します。プロキシが MARS に接続するときの送信元のアドレスです。MARS は、このアドレスから届いたリクエストの `X-Forwarded-For` ヘッダーを信頼し、その中のクライアントのアドレスを使います。信頼するプロキシを設定しない場合、`X-Forwarded-For` は無視されます。

```sh
# 単独のアドレス
MARS_TRUSTED_PROXIES=192.168.1.10

# 複数のアドレスと CIDR
MARS_TRUSTED_PROXIES=192.168.1.10,172.18.0.0/16
```

### Host ヘッダー

プロキシは元のリクエストの `Host` ヘッダーを MARS に渡してください。ポート番号を含むアドレス（例: `:8443`）を使う場合、この設定を誤るとログインできなくなります。

nginx では次のように書きます。

```nginx
proxy_set_header Host $http_host;
```

`$host` ではなく `$http_host` を使ってください。`$host` は、`:8443` のような非標準のポート番号を取り除くため、MARS から見たリクエストの `Host` が変わってしまいます。

### X-Forwarded-Proto

HTTPS で公開する場合は、プロキシが `X-Forwarded-Proto` に `https` を設定してください。nginx では次のように書きます。

```nginx
proxy_set_header X-Forwarded-Proto $scheme;
```

MARS は、このヘッダーが `https` のとき、ログインの Cookie に `Secure` 属性を付けます。この設定がないと、HTTPS で使っていても Cookie が HTTP として扱われます。HTTPS の接続が必要な PWA のインストールについては、[Docker でのインストール](install/docker.ja.md#https-とスマホへのインストール) を参照してください。

### イベントの配信（/api/v1/events）

画面をリアルタイムに更新するため、MARS は `/api/v1/events` で SSE（サーバー送信イベント）を使います。nginx のようにレスポンスをバッファリングするプロキシでは、この経路のバッファリングを止めてください。

```nginx
location /api/v1/events {
    proxy_pass http://127.0.0.1:25600;
    proxy_buffering off;
}
```

バッファリングを止めないと、イベントがすぐに届かず、画面が更新されないことがあります。

### 例: nginx の設定

```nginx
server {
    listen 443 ssl;
    server_name mars.example.com;

    # 証明書の設定は省略しています

    location / {
        proxy_pass http://127.0.0.1:25600;
        proxy_set_header Host $http_host;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    location /api/v1/events {
        proxy_pass http://127.0.0.1:25600;
        proxy_set_header Host $http_host;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_buffering off;
    }
}
```

この例では、nginx が MARS と同じホストで動き、MARS へ `127.0.0.1` から接続するものとしています。その場合は `MARS_TRUSTED_PROXIES=127.0.0.1` を設定します。MARS を Docker で動かしている場合、nginx からの接続元は通常 Docker のブリッジのアドレス（例: `172.17.0.1`）になります。そのときは、MARS が実際に見ている接続元のアドレスを設定してください。

## 待ち受けアドレス

`MARS_HOST` を指定しない場合、MARS はすべてのインターフェースで待ち受けます。ただし、サインインと初期設定の API を除き、API を使うにはサインインが必要です。

`MARS_HOST` で待ち受けアドレスを絞れます。たとえば、`127.0.0.1` にすると、同じホストからだけ接続できます。

```sh
MARS_HOST=127.0.0.1
```

Docker で動かす場合は、`MARS_HOST` を `127.0.0.1` にしないでください。コンテナの中で `127.0.0.1` だけで待ち受けると、`-p` で公開したポートからの接続が届かなくなります。

## サーバー設定画面

サーバー設定画面は **管理 > サーバー設定** にあります。次の設定を変更できます。保存するには、画面下の保存のバーで **保存** を選んでください。

### 一般

| 項目 | 説明 |
| --- | --- |
| ポート | 待ち受けるポートです。変更は、サーバーを再起動すると反映されます。環境変数 `MARS_PORT` が設定されている場合は、そちらが使われます |
| タスクの同時実行数 | スキャンやサムネイルの作成などを、同時に実行する数です。1 から 16 までの値を選びます。変更は、サーバーを再起動すると反映されます |

### サムネイル

| 項目 | 説明 |
| --- | --- |
| サイズ | 小、中、大、特大から選びます |
| 形式 | JPEG、WebP、AVIF から選びます |

どちらの設定も新しく作るサムネイルから反映されます。既存のサムネイルを作り直すには、シリーズまたはライブラリの **表紙を作り直す** を使います。OPDS と Komga 互換 API には、形式にかかわらず、常に JPEG で返します。

### 認証

| 項目 | 説明 |
| --- | --- |
| ログイン保持の日数 | ログイン状態を保持する日数です |
| ログイン画面 | ログインしていない人に見せる背景を選びます。**惑星**（MARS の惑星と軌道だけを表示）、**シリーズの表紙**（最近追加したシリーズの表紙を並べる）、**巻の表紙**（最近追加した巻の表紙を並べる）から選びます |

**シリーズの表紙** と **巻の表紙** を選ぶと、ログインしていない人にも表紙が見えます。

### 連携

| 項目 | 説明 |
| --- | --- |
| OPDS | OPDS 1.2 のカタログを有効にします。Panels、Chunky、KyBook などの電子書籍アプリで使います。画面には `http://<ホスト>:25600/opds/v1.2/catalog` の形式のアドレスと、**コピー** ボタンが表示されます |
| Komga 互換 API（Mihon） | Mihon の Komga 拡張とトラッカーで使う API を有効にします。画面には `http://<ホスト>:25600/komga` の形式のアドレスと、**コピー** ボタンが表示されます |

どちらの連携もサインインには MARS のユーザー名とパスワード、または API キーを使います。

### コレクション

| 項目 | 説明 |
| --- | --- |
| 空のコレクションを自動で削除する | ゴミ箱を空にしたとき、またはライブラリを削除したときに、シリーズがひとつも残らなかったコレクションを削除します |
