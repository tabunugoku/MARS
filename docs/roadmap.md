# Roadmap

v1.0.0 includes the features up to Phase 11. This page describes the plans after that.

The order below is a guide. Priorities can change based on demand and bug reports. Send requests and feedback as [GitHub issues](https://github.com/tabunugoku/MARS/issues).

## Next up (Phase 12)

- Browse pages for publishers, genres and tags: Find series by publisher or genre.
- Oneshots folder: Treat each one-shot in a folder of one-shot works as a separate series.
- Aggregate series metadata from volumes: Collect authors, tags and release dates from a series' volumes automatically.

## Phase 13

- Viewing limits by age rating and shared labels: Limit which books each user can see, based on age ratings and labels on books.
- Authentication history (activity log): View records of sign-ins.
- Update check: Check whether a newer version of MARS is available. It is off by default.

## Phase 14

- KOReader progress sync (kosync): Sync progress from KOReader with MARS.
- OPDS 2 and DiViNa: Support the newer OPDS version and delivery in the DiViNa format.

## Under consideration

We will decide whether to take up the following features based on demand. They are not in the plans above.

- EPUB (both fixed-layout and reflowable)
- EPUB reader (font settings, themes)
- EPUB metadata
- Reading Mylar `series.json` files
- Reading ISBN barcodes
- Detecting duplicate files by file hash
- Detecting and removing duplicate pages (such as ad pages) by page hash
- Converting to CBZ
- Fixing wrong file extensions
- Importing files from outside the library (copy or move)
- Syncing with Kobo devices
- Compatibility with Komf (an external metadata tool)
- Sign-in with OAuth2 / OIDC
