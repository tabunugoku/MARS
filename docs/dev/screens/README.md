# 画面仕様書

1画面（または1グループ）1ファイル。Haiku は担当の仕様書と `.claude/skills/mars-design/SKILL.md` を読んでから実装する。

共通のルール
- 編集してよいのは「ファイル」欄に書いたものだけ。`routes/<name>.tsx` を `routes/<name>/index.tsx` に置き換えて、同じフォルダに部品を分けるのは可。
- 共通部品（`components/media/*`、`components/shell/*`、`api/*`）を変えたいときは、変えずに報告する。
- 文言は日本語。仕様書の文言はそのまま使ってよい。
