# OPDS と Komga 互換 API

MARS は、ほかのアプリがすでに使っている 2 つの方式で本を公開できます。

- **OPDS 1.2**（OPDS-PSE によるページ送信）: Panels、Chunky、KyBook などの電子書籍アプリで使います。
- **Komga 互換 API**: Mihon の Komga 拡張と、Mihon の Komga トラッカーで使います。

どちらも既定では無効です。使うには、管理者が有効にします。

## 有効にする

管理 > サーバー設定 の「連携」で、次の 2 つのスイッチを有効にします。

| スイッチ | 接続先 |
| --- | --- |
| OPDS | `http://HOST:25600/opds/v1.2/catalog` |
| Komga 互換 API（Mihon） | `http://HOST:25600/komga` |

`HOST` は、MARS を動かしているコンピューターの名前か IP アドレスに置き換えてください。サーバー設定の画面には、その画面を開いているブラウザのアドレスをもとに組み立てたアドレスが表示され、横のボタンでコピーできます。

無効のときは、これらのアドレスは見つからないと応答します。

## サインインする

どちらの方式も次のどちらかでサインインします。

- MARS のユーザー名（またはメールアドレス）とパスワード
- API キーを、パスワードの欄に入力する（ユーザー名は任意の文字列で構いません）

API キーの作り方は[ユーザーと権限](users.ja.md#api-キー) を参照してください。

## OPDS アプリで使う

1. アプリで、OPDS のカタログを追加します。
2. アドレスに `http://HOST:25600/opds/v1.2/catalog` を入力します。
3. ユーザー名とパスワード、または API キーを入力します。

カタログには、次の項目が表示されます。

- 続きを読む
- 最近追加されたシリーズ
- 最近追加された巻
- ライブラリ
- コレクション
- リーディングリスト

検索もできます。アプリの検索欄で、シリーズを探せます。

ダウンロードは、「ファイルのダウンロードを許可」の権限があるユーザーだけができます。ページを読むには、「ページのストリーミングを許可」の権限が必要です。

## Mihon で使う

### Komga 拡張

1. Mihon で、Komga 拡張をインストールします。
2. 拡張の設定で、アドレスに `http://HOST:25600/komga` を入力します。
3. ユーザー名とパスワード、または API キーを入力します。

### Komga トラッカー

Komga トラッカーはユーザー名やパスワードを送らずに接続します。代わりに、Komga 拡張でサインインしたときに MARS が発行した Cookie を使います。そのため、トラッカーを使う前に、上の Komga 拡張で一度サインインしてください。

## できること、できないこと

| 項目 | 状態 |
| --- | --- |
| 本の一覧、検索、ライブラリ、コレクション、リーディングリストの閲覧 | できます。 |
| ページの表示、表紙の表示 | できます。 |
| 本のダウンロード | ダウンロードの権限があるユーザーだけができます。 |
| 読書の進捗の保存 | できます。MARS の画面と同じ進捗として扱われます。 |
| 本、シリーズ、ライブラリの変更（メタデータの編集、追加、削除） | できません。 |
| スキャン、ライブラリの管理 | できません。 |
| OPDS v2 | 対応していません。 |

## 注意

- これらのアプリは実機での動作確認を十分に行っていません。動かない場合や、表示が正しくない場合は、[GitHub の Issue](https://github.com/tabunugoku/MARS/issues) で報告してください。
- MARS の外からつなぐ場合は、HTTPS で接続してください。認証の情報はリクエストのたびに送られます。HTTPS の設定は[Docker での導入](install/docker.ja.md) を参照してください。
