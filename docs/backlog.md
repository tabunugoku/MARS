# 残課題（モックアップ段階で見送ったもの）

2026-11-10 の Codex レビューと Opus の確認から。実装フェーズで対応する。

- リーダー: 「原寸」「高さに合わせる」でページが画面より大きいとき、タッチで画像を動かせない。パン操作とページ送りの切り分けが必要（Codex #10）
- リーダー: ページ一覧と Webtoon 表示が全ページ分の要素を一度に作る。数百ページの本では仮想化する（Codex #17）
- ライブラリ種別のアイコンとアプリアイコンを kubai-icons で作る（今は Keyline の仮アイコン）
- `unslop` での仕上げの見直しは未実施
- 「絞り込み」「巻数の昇順」ボタンなど、アイコンと文字が縦に折り返す箇所がある（Button の leadingIcon を使う）
- Dialog の閉じるボタンの読み上げが英語（"Close"）。Fluid の部品を包んで日本語にする
- 管理画面の保存・追加は画面上だけで、API（モック）に書き込み系がない
