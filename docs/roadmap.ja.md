# ロードマップ

v1.0.0 にはフェーズ 11 までの機能が含まれています。この資料では、その後の予定を説明します。

ここに書いた順番は目安です。優先順位は需要や不具合の報告によって変わることがあります。要望や意見は [GitHub の Issue](https://github.com/tabunugoku/MARS/issues) で伝えてください。

## 次の予定（フェーズ 12）

- 出版社、ジャンル、タグなどの閲覧ページ: 出版社やジャンルから、シリーズを探せるようにします。
- Oneshots ディレクトリ: 読み切りの作品を集めたフォルダを、単話ごとに独立したシリーズとして扱えるようにします。
- シリーズのメタデータを巻から集約する: 著者、タグ、発売日を、シリーズの巻から自動で集めます。

## フェーズ 13

- 年齢区分と共有ラベルによる閲覧制限: 年齢区分や、本に付けたラベルによって、ユーザーごとに見られる本を制限します。
- 認証履歴（アクティビティログ）: サインインの記録を見られるようにします。
- 更新の確認: MARS の新しいバージョンがあるかを確認します。既定ではオフです。

## フェーズ 14

- KOReader の進捗同期（kosync）: KOReader で読んだ進捗を、MARS と同期します。
- OPDS v2 と DiViNa: OPDS の新しいバージョンと、DiViNa 形式の配信に対応します。

## 検討中

次の機能は、需要を見て取り上げるかどうかを決めます。上の予定に含まれていない項目です。

- EPUB（固定レイアウトとリフローの両方）
- EPUB リーダー（フォントの設定、テーマ）
- EPUB のメタデータ
- Mylar の `series.json` の読み取り
- ISBN バーコードの読み取り
- ファイルのハッシュによる、重複ファイルの検出
- ページのハッシュによる、重複ページ（広告ページなど）の検出と削除
- CBZ への変換
- 誤った拡張子の修正
- ライブラリの外にあるファイルの取り込み（コピーまたは移動）
- Kobo 端末との同期
- Komf（外部のメタデータ取得ツール）との互換
- OAuth2 / OIDC によるログイン
